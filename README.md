# GreenGoals

GreenGoals is a React and Vite frontend for making sustainable habits social. The app includes a public landing page, Google sign-in, and a responsive demo dashboard with points, challenges, groups, a leaderboard, and a profile.

## Run locally

```sh
npm install
npm run dev
```

### Google sign-in

Create a Google OAuth **Web application** client ID in the Google Cloud Console. Add the local and deployed origins you use to its authorized JavaScript origins, then create a `.env` file in the project root:

```dotenv
VITE_GOOGLE_CLIENT_ID=your-client-id.apps.googleusercontent.com
```

Restart the Vite server after changing `.env`. Without a client ID, the sign-in dialog explains how to configure it and still offers a demo account.

Google Identity Services runs in the browser and returns an ID token. This frontend decodes the token only to display the signed-in user's name, email, and picture; decoding is **not** token verification. Before using Google sign-in to protect real user data or persist account actions, send the credential to a backend and verify its signature, audience, and expiry with Google's supported authentication library.

## Demo dashboard

The dashboard's sample challenges, group, leaderboard, and starting points are frontend demo data. Completing a challenge updates the displayed points for the current page session; it does not persist to a server. The challenge copy is illustrative and is not generated by a connected Gemini service. Add the application's API and Gemini integration before treating points, rankings, groups, or challenge completion as authoritative.
